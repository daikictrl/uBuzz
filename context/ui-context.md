# U-Buzz — UI Context

## Design Tool

All visual design is generated by Google Stitch via MCP.
This file defines the design tokens and behavioral rules
that Stitch must respect when generating any screen or
component for U-Buzz.

## Screen Layouts

### Auth Screen
- Full screen dark background (#0a0a0a)
- App name "U-Buzz" large at top
- Tagline: "IUGET's Campus Network" below name
- Scrollable form card with rounded inputs
- Toggle link at bottom to switch Sign Up / Login

### Home Feed Screen
- Edge to edge, no padding, no safe area top
- Status bar: hidden or transparent
- Videos fill 100% width and 100% screen height
- Feed tabs float over video at top (absolute positioned)
- Action buttons column on bottom right
- User info on bottom left
- Bottom tab bar visible over the feed

### Video Card
- Full screen (100vw × 100vh)
- Video player as base layer (resizeMode: cover)
- Gradient overlay bottom 40% of card
- Info panel bottom left: 16px from edge, 100px from bottom
- Action buttons bottom right: 16px from edge, 100px from bottom
- Mute button top right: 16px from edge, 60px from top

### Upload Screen
- Standard screen with safe area
- Video preview: full width, 16:9 aspect ratio
- Caption input below preview
- Post button fixed at bottom

### Profile Screen
- Scrollable screen
- Avatar centered at top
- Stats row: 3 equal columns
- Video grid: 3 columns, 2px gaps, square cells

### Bottom Sheets (Comments, Edit Profile, Report)
- Background: #111111
- Top corners rounded: 20px
- Handle bar: short, centered, #2a2a2a
- Backdrop: rgba(0,0,0,0.5)

### Search Screen
- Standard screen with safe area
- Search input fixed at top
- Results list below

## Component Patterns

### Buttons
Primary: filled accent color, full width, 52px height
Secondary: outlined accent color, full width, 52px height
Destructive: filled #EF4444
Icon button: 44px × 44px minimum tap target

### Inputs
Height: 52px
Background: #1a1a1a
Border: 1px solid #2a2a2a
Active border: 1px solid accent (#8B5CF6)
Error border: 1px solid #EF4444
Padding horizontal: 16px
Error text: #EF4444, 12px, below the input

### Action Buttons (Feed)
Icon size: 28px
Color: white
Count label: 12px, white, centered below icon
Spacing between buttons: 24px
Like active: #EF4444 filled heart

### Bottom Tab Bar
Background: #111111
Active icon: accent (#8B5CF6)
Inactive icon: #4B5563
Upload tab button: 56px circle, accent fill, raised (+8px)

### Skeleton Loaders
Base: #1a1a1a
Shimmer: #2a2a2a
Animation: left to right, 1.5s loop

### Badges (duration, notification)
Background: rgba(0,0,0,0.6)
Text: white, 10px
Padding: 2px 6px
Border radius: 9999px

## Interaction States

| State      | Visual Change                              |
|------------|--------------------------------------------|
| Pressed    | 0.85 opacity scale down slightly           |
| Loading    | Spinner replaces button label              |
| Disabled   | 0.4 opacity, not tappable                  |
| Error      | Red border on input, red text below        |
| Success    | Brief toast (2 seconds) at screen bottom   |

## Animation Guidelines

- Like heart burst: scale 0 → 1.3 → 1, fade out over 800ms
- Sheet open/close: spring animation (default gorhom config)
- Tab switch: instant (no cross-fade on feed)
- Skeleton shimmer: linear, 1.5s loop, left to right
- Double-tap heart: appears at tap coordinates, not centered
